## 项目简介
本基于哈夫曼(Huffman)编码算法实现纯文本文件的无损压缩

```txt
└── text.huff # 最终压缩的文件
```

## Huffman编码核心思想
为出现频率高的字符分配更短的二进制编码,频率低的字符分配更长的编码,从而减少文本的总存储体积.

## 项目功能
- 自动统计文本文件中字符的出现频率
- 构建哈夫曼树并生成字符-编码映射字典, 输出为.json文件
- 将文本转换为二进制编码并保存为压缩文件(.huff)
- 输出压缩率、平均编码长度等指标

## 相关关键内容实现
- 构建 Huffman 树: 自定义 Huffman 树结点
- 按照出现频率进行排序: 使用 python 自带 heapq 库, 构建最小堆
- 读入文件统计字符频次/输出压缩后文件: 使用python相关内置库完成

## 核心算法分析

### 压缩比率分析
本次测试使用《傲慢与偏见》英文文本(`Pride_and_Prejudice.txt`):
- 原始文件大小:757,533 字节
- 压缩后文件大小:422,863 字节
- **压缩率** = 压缩后大小 / 原始大小 = 422863 / 757533 ≈ 55.8%
- **空间节省**:≈ 44.2%
- 平均编码长度:4.52 位/字符(对比 ASCII 编码的 8 位/字符,编码长度减少 43.5%)


### 算法复杂度分析
以下, $n$ 为文本总字符数,$k$ 为不同字符种类数(远小于 $n$)
| 步骤| 时间复杂度| 空间复杂度|说明|
|:---:|:---:|:---:|:---:|
| 字符频率统计| $O(n)$| $O(k)$|遍历带压缩文本|
| 哈夫曼树构建| $O(k \log k)$| $O(k)$| 最小堆的插入/弹出操作均为 $O(\log k)$,需执行 $k-1$ 次合并操作|
| 生成哈夫曼编码  | $O(k)$| $O(k)$| 递归遍历哈夫曼树,每个叶子节点(字符)仅访问一次 |
| 文本编码转换| $O(n)$| $O(n)$| 遍历文本并拼接二进制编码字符串|
| 整体复杂度  | $O(n + k \log k)$| $O(n + k)$| 实际中 $k \log k$ 远小于 $n$,整体复杂度近似 $O(n)$  |

### 核心算法伪代码
```C
// 统计字符频率
FUNCTION get_char_freq(file_path):
    // 读取文本文件
    text = READ_FILE(file_path, encoding="utf-8")
    IF text IS EMPTY:
        RETURN EMPTY_LIST
    
    // 统计每个字符出现次数
    char_count = EMPTY_DICT
    total_chars = LENGTH(text)
    FOR char IN text:
        char_count[char] = char_count.get(char, 0) + 1
    
    // 计算频率并生成 (频率, 字符) 列表
    char_freq_list = EMPTY_LIST
    FOR char, count IN char_count.items():
        freq = count / total_chars
        ADD (freq, char) TO char_freq_list
    
    RETURN char_freq_list

// 构建哈夫曼树
FUNCTION build_huffman_tree(char_freq_list):
    // 初始化最小堆(按频率升序)
    heap = EMPTY_HEAP
    FOR freq, char IN char_freq_list:
        PUSH Node(char, freq, None, None) TO heap
    
    // 循环合并最小的两个节点,直到堆中只剩一个节点(根节点)
    WHILE LENGTH(heap) >= 2:
        node1 = POP MIN FROM heap  // 取出频率最小的节点
        node2 = POP MIN FROM heap  // 取出频率次小的节点
        // 生成合并节点(无字符,频率为两节点之和)
        merged_node = Node(None, node1.freq + node2.freq, node1, node2)
        PUSH merged_node TO heap
    
    // 返回哈夫曼树根节点
    RETURN POP MIN FROM heap

// 生成哈夫曼编码
FUNCTION gen_huffman_code(node, current_code, huffman_dict):
    IF node IS NOT None:
        // 叶子节点(对应单个字符):记录编码
        IF node.left IS None AND node.right IS None:
            huffman_dict[node.char] = current_code
        // 递归遍历左子树:编码追加 0
        gen_huffman_code(node.left, current_code + "0", huffman_dict)
        // 递归遍历右子树:编码追加 1
        gen_huffman_code(node.right, current_code + "1", huffman_dict)

// 生成压缩文件
FUNCTION gen_output(input_path, huffman_dict, output_path, dict_path):
    // 读取原始文本并转换为二进制编码字符串
    text = READ_FILE(input_path, encoding="utf-8")
    binary_str = ""
    FOR char IN text:
        binary_str += huffman_dict[char]  // 字符替换为哈夫曼编码
    
    // 保存编码字典(解压必备)
    SAVE_JSON(huffman_dict, dict_path)
    
    // 二进制字符串补 0 至 8 的倍数(字节对齐)
    padding_bits = (8 - LENGTH(binary_str) % 8) % 8
    binary_str += "0" * padding_bits
    
    // 转换为字节数组并保存(首字节记录补 0 位数)
    byte_array = EMPTY_BYTEARRAY
    FOR i FROM 0 TO LENGTH(binary_str) STEP 8:
        byte = BINARY_TO_INT(binary_str[i:i+8], 2)
        ADD byte TO byte_array
    
    // 写入二进制压缩文件
    WRITE_FILE(output_path, padding_bits.to_bytes(1) + byte_array, mode="wb")
```

## 注意事项
1. **压缩文件类型**:生成的 `.huff` 文件是二进制文件,无法用文本编辑器直接打开,需通过解压函数还原为文本;
2. **编码字典依赖**:解压时必须使用压缩生成的 `huffman_dict.json`,否则无法正确还原文本;

- 算法整体时间复杂度为 $O(n)$($n$ 为文本长度),在处理长篇文本时效率较高.
